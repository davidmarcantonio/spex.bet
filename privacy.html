Privacy

Short version: Spex Glance runs on your Mac, talks only to Kalshi, and has no server of its own.

Your Kalshi API key

Stored in your macOS Keychain. Used only to call Kalshi's API from your Mac. It is never sent anywhere else. The app requires a read-only key and cannot place, amend, or cancel orders.

Your positions and balances

Fetched from Kalshi, shown on screen, held in memory while the app runs. Not logged, not uploaded, not shared.

What is collected

When the app checks for updates (Sparkle), it sends a standard anonymous system profile: app version, macOS version, and CPU architecture. That is used to count installs and decide what to keep supporting. There is no account, no identifier tied to you, and no position or financial data in that request. You can turn off automatic update checks in Settings.

This website

Static pages hosted on GitHub Pages. No analytics script, no cookies set by the site. GitHub's own hosting logs apply; see GitHub's privacy statement. Fonts are loaded from Google Fonts, which is subject to Google's policies.

Third parties

Kalshi (their API, under their terms), GitHub (downloads and this site), Google Fonts (this site only), Ko-fi (only if you click the tip link).
