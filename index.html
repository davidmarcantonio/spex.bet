The gap

Kalshi is fine for trading. It's not built for keeping tabs.

What you get on Kalshi today

Your open positions live inside the web portfolio page or the phone app, mixed in with everything else, behind a login and a few taps. If you want to see how tonight's games are going, you go look. Then you go look again.

What Spex Glance adds

A single pane of glass for your active sports positions, sitting in a Mac window or up in the menu bar. Grouped by game, live clocks, current chance, what it pays, and a running P&L. Nothing to trade, nothing to accidentally click.

Scope, on purpose

Active positions only. Sports only. Read only.

It does

  • Show every open sports position: MLB, NHL, ATP/WTA and whatever else Kalshi tags as sports
  • Group positions by game, with start times and live "minutes in" clocks
  • Show cost, current chance, and payout per side; combos with each leg listed
  • Mark games Final and flip legs to Won / Lost once Kalshi settles
  • Stream live P&L to the menu bar over Kalshi's WebSocket

It doesn't

  • Place, amend, or cancel orders. Ever. The key it uses can't.
  • Display non-sports positions (they're counted in your totals, not listed)
  • Show history, settled trades, or charts
  • Tell you what to bet. It relays Kalshi's numbers; it has no opinion.
  • Phone home. No accounts, no analytics beyond an anonymous install count
Features

Built for people who leave games running in the background.

Menu bar P&L

Live unrealized P&L in the menu bar, with every position in the dropdown. Priced from Kalshi's ticker feed, not a polling loop.

Work Mode

Hides the Spex icon and the dollar sign so a shared screen at the office shows nothing worth asking about.

Kalshi's own vocabulary

Cash / Positions / Total, "Yes · Dodgers", "No · Over 8.5 runs". The layout mirrors Kalshi's portfolio so nothing needs translating.

Filter and sort

Sport pills (Baseball, Hockey, Tennis, Combos) and sort by Live first, earliest, or latest start. ⌘E expands or collapses everything.

Desktop widget

Small, medium, and large widgets for the desktop or Notification Center, for the "is it still close?" check.

Light, dark, and yours

Follows the system or pick one. Auto-updates via Sparkle. Launch at login if you want it always on.

Setup

Three steps, about five minutes.

Kalshi has no "sign in with Kalshi" for third-party apps, so connecting is a one-time manual step on kalshi.com. The app walks you through it.

  1. Download and open Spex GlanceGrab the latest release from GitHub. It's notarized, so macOS opens it like any other app.
  2. Create a read-only API key on KalshiThe connect wizard sends you to the right page on kalshi.com, you create a key with read-only permissions, and drop the key file into the app. Keys stay in your macOS Keychain.
  3. GlanceYour open sports positions show up grouped by game. Turn on the menu bar item, pick Work Mode if you need it, and get on with your day.

FAQ

Questions people ask before installing a thing that touches their money.

Is this affiliated with Kalshi?

No. Spex Glance is an independent open-source project. It is not affiliated with, endorsed by, or supported by Kalshi. "Kalshi" is their trademark.

Can it trade on my account?

No. It runs on a read-only API key. Kalshi enforces that on their end; the app has no order code to begin with. If Kalshi ever changes how keys work, the read-only requirement still stands in the app.

Where does my key go?

Into your macOS Keychain, on your Mac. The app talks directly to Kalshi's API. There's no Spex server in between.

Why sports only?

Because that's the point. Sports positions resolve on a clock, tonight, and that's what you want to watch. Other open positions still count toward your Cash / Positions / Total tiles; they just aren't listed.

Are the numbers real time?

Prices come from Kalshi's WebSocket ticker, so they're as current as Kalshi sends them. They can lag or be wrong. Confirm on Kalshi before acting on anything.

What does it cost?

Nothing. MIT license, source on GitHub. If it saves you a few tab-switches a night, there's a Ko-fi link in the About tab.

Does it collect anything?

An anonymous install count with macOS version and CPU architecture, via Sparkle's update check, so I know whether anyone is using it. No account, no identifiers, no position data. See the privacy note.

Is there an iPhone version? A self-hosted one?

iOS is on the list, not built yet. If you run a homelab, the companion project Haruspex is a self-hosted Kalshi sports-market monitor with a web dashboard; Spex Glance works on its own and doesn't need it.
